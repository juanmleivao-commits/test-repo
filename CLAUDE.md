# Proyecto
Herramientas de automatización en Python para gestión de CrowdStrike Falcon y auditoría.

# Comandos
- Ejecutar script principal: `python Menu_v14.py`

# Reglas Arquitectónicas y de Código
- Usa SIEMPRE Type Hints de Python en los parámetros y retornos de todas las funciones.
- Añade comentarios detallados explicando la lógica operativa y de auditoría.
- Nunca dejes tokens o credenciales de API hardcodeadas en el código; asume siempre el uso de variables de entorno.
